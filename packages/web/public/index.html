Access Model

  • Least privilege: installation tokens scoped to the repos the app is installed on.
  • Signed webhooks: HMAC SHA-256 verification on every GitHub event.
  • Sandboxed codemods: mechanical renames only; AI codemods require an explicit provider + output validation.
  • Verify-before-PR: builds must pass (tsc) before any migration PR is opened.
  • Audit trail: every scan and PR is recorded in the activity feed.
